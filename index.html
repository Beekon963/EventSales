EventSalesPortal利用規約

株式会社UPDRAFT（以下「当社」といいます。）は、当社が運営するログイン制ウェブサイト「EventSalesPortal」の利用条件を、以下のとおり定めます。

第1条（目的及び適用）

  1. 本規約は、「EventSalesPortal」（以下「本サービス」といいます。）の利用及び本サービスを通じて成立する個別の業務委託契約に関する共通条件を定めるものです。
  2. 本規約は、本サービスの利用者と当社との間に適用されます。
  3. 利用者は、本規約の内容を確認し、これに同意した上で本サービスを利用するものとします。

第2条（定義）

本規約において、次の各号に掲げる用語は、それぞれ次の意味を有します。

  1. 「協力会社」とは、携帯電話販売に関する催事、イベントその他の販売促進業務を企画又は運営し、当社に販売促進業務、催事運営業務その他の業務を委託する事業者をいいます。
  2. 「利用者」とは、本規約に同意し、本サービスへの登録を認められた個人又は個人事業主をいいます。
  3. 「委託業務」とは、当社が協力会社から受託した販売促進業務、催事関連業務その他の業務のうち、当社が利用者に委託する業務をいいます。
  4. 「案件」とは、当社が、特定の実施場所、実施予定日その他の条件を定めて、利用者への委託を検討する個別の委託業務をいいます。
  5. 「案件情報」とは、本サービスに掲載される、案件の概要、実施場所、実施予定日、業務内容、想定する委託報酬、業務区分、交通関連費用その他の情報をいいます。
  6. 「関心表明」とは、利用者が、案件について詳細情報の提供又は個別条件の提示を希望する旨を、当社に連絡することをいいます。
  7. 「個別条件」とは、個別案件について当社が利用者に提示する、委託業務の内容、委託報酬、実施場所、実施予定日、役務提供時間帯、費用、支払期日、キャンセル条件その他の取引条件をいいます。
  8. 「個別契約」とは、個別条件について当社と利用者が合意することにより、案件ごとに成立する業務委託契約をいいます。
  9. 「業務仕様」とは、委託業務の目的、範囲、成果基準、品質基準、顧客対応基準、法令遵守事項、情報セキュリティ基準、安全上の注意事項及び禁止事項をいいます。
  10. 「公式連絡手段」とは、本サービス、当社が指定する電子メール、当社の業務用LINEアカウントその他当社が指定する連絡手段をいいます。
  11. 「顧客情報」とは、催事又は店舗の来訪者、通信契約の申込者その他の顧客に関する個人情報、申込情報、本人確認情報、通信契約情報、端末購入情報、相談内容その他一切の情報をいいます。
  12. 「店舗担当者等」とは、協力会社、携帯電話事業者、販売店舗、催事会場、施設管理者その他案件に関係する第三者の役員、従業者又は担当者をいいます。
  13. 「登録者等」とは、本サービスの利用者、登録希望者、当社の業務委託先候補者、又は当社から委託業務を受託し若しくは受託したことのある者をいいます。

第3条（本規約と個別契約との関係）

  1. 本規約と個別条件の内容が矛盾する場合は、個別条件が優先して適用されます。
  2. 利用者が独自に定める契約条件、注文書、請求書等の記載は、当社が書面又は電磁的方法により明示的に承諾しない限り、個別契約の内容となりません。

第4条（本サービスの性質）

  1. 本サービスは、当社が協力会社から受託した販売促進業務、催事関連業務その他の業務の一部について、業務委託先の候補者又は既存の業務委託先に情報を提供し、個別案件の受託可否を確認し、契約及び業務上の連絡を行うためのポータルです。
  2. 本サービスは、求人サイト、職業紹介サービス、労働者派遣サービス又は労働者供給サービスではありません。
  3. 当社は、協力会社を代理して利用者との契約成立をあっせんするものではなく、当社自身を委託者として、利用者との間で個別契約を締結します。
  4. 協力会社又は店舗担当者等と利用者との間に、本サービスを通じて雇用契約又は業務委託契約が成立するものではありません。

第5条（登録資格）

本サービスへの登録を希望する者は、次の各号のすべてを満たさなければなりません。

  1. 成年であり、完全な行為能力を有すること。
  2. 個人又は個人事業主として、独立して業務を受託し遂行する意思及び能力を有すること。
  3. 本人確認、資格確認、法令遵守確認及び情報セキュリティ確認に協力できること。
  4. 登録情報及び当社への申告内容が正確かつ最新であること。
  5. 過去に重大な法令違反、不正な販売行為、顧客情報の漏えい、無断キャンセルその他委託先としての信用を著しく損なう行為をしていないこと。
  6. 反社会的勢力に該当しないこと。

第6条（登録手続）

  1. 登録希望者は、当社所定の方法により、氏名、住所、連絡先、事業情報、経歴、保有資格、報酬振込先その他当社が求める事項を申告します。
  2. 当社は、登録希望者に対し、本人確認書類、資格証明書、在留資格に関する資料その他合理的に必要な資料の提出又は面談による確認を求めることがあります。
  3. 当社は、登録希望者が本契約の要件を満たさない場合、申告内容に疑義がある場合又は本サービスの適正な運営上支障があると合理的に判断した場合、登録を承認しないことがあります。

第7条（案件情報）

  1. 当社は、本サービスに、案件の概要、実施場所、実施予定日、委託業務の内容、想定する委託報酬、業務区分、交通関連費用その他の案件情報を掲載します。
  2. 案件情報は、個別条件が提示される前の暫定的な情報を含むことがあります。当社は、個別契約成立前であれば、案件情報を変更し、掲載を終了し、又は案件の案内を中止することができます。
  3. 案件情報の掲載は、当社による契約の申込みではなく、個別契約の成立、案件の実施又は委託報酬の発生を保証するものではありません。
  4. 利用者は、案件情報を自己の受託判断のためにのみ利用し、当社の承諾なく第三者に提供し、転載し、又は外部に公開してはなりません。また、利用者は、案件情報を利用して、当社の承諾なく、登録者等に対し、当社又は本サービスを介さない案件の提案、業務のあっせん、勧誘、引き抜き、外部グループ等への招待、直接契約の働き掛けその他これらに類する行為をしてはなりません。

第8条（関心表明）

  1. 利用者は、案件に関心がある場合、当社所定の方法により関心表明を行うことができます。関心表明は、案件の詳細確認又は個別条件の提示を求める連絡にすぎず、利用者による契約の申込み又は承諾ではありません。
  2. 当社は、関心表明を受けた場合であっても、利用者に個別条件を提示する義務を負わず、案件の案内又は契約成立を保証しません。

第9条（個別条件の提示及び個別契約の成立）

  1. 当社は、利用者への委託を希望する場合、公式連絡手段を通じ、個別条件を電磁的方法により提示します。
  2. 個別契約の法的性質は個別条件に定めます。個別条件に別段の定めがない場合、個別契約は、特定の販売成果を保証するものではなく、合意された業務の適切な遂行を目的とする準委任型の業務委託契約とします。

第10条（独立した事業者としての関係）

  1. 当社と利用者との関係は、案件ごとに成立する業務委託契約に基づく独立した事業者間の関係です。
  2. 利用者は、各案件を受託するか否かを、自らの判断で自由に決定できます。
  3. 本規約又は個別契約は、当社と利用者との間に雇用契約、労働契約、共同事業、組合、代理、労働者派遣その他これらに類する関係を成立させるものではありません。
  4. 利用者は、自らの事業として、自己の判断と責任により委託業務を遂行します。
  5. 案件の性質上、個別条件において役務提供日、場所及び時間帯が指定されることがあります。これらは、催事の開催時間、施設の利用条件、顧客対応その他委託業務の目的を達成するための契約上の履行条件として定めるものです。

第11条（業務仕様及び遵守事項）

  1. 利用者は、個別契約、業務仕様及び適用法令に従い、善良な管理者の注意をもって委託業務を遂行します。
  2. 当社は、利用者に対し、業務仕様又は遵守事項として提示することがあります。
  3. 前項の業務仕様等は、委託業務の目的、品質、法令遵守、安全及び顧客保護を確保するための契約上の条件として提示するものであり、利用者の日常生活、人事、服務又は事業全般を管理するものではありません。

第12条（協力会社及び店舗担当者等との連絡）

  1. 委託業務に関する契約条件の提示、業務仕様の共有、重要な連絡及び条件変更は、当社が行います。
  2. 協力会社又は店舗担当者等は、利用者に対し、委託業務の具体的な方法、順序、追加作業、役務提供時間帯、委託報酬その他の契約条件を直接変更する権限を有しません。
  3. 利用者が協力会社又は店舗担当者等から、委託業務の範囲、方法、順序、追加作業、役務提供時間帯その他の重要事項に関する直接の依頼又は変更要請を受けた場合、利用者は、原則として当社に確認し、当社を通じて対応します。
  4. 次に掲げる事項については、利用者は、協力会社又は店舗担当者等から直接情報を受け、又は必要な対応を行うことができます。
    1. 会場の位置、レイアウト、施設利用方法、商品在庫その他の事実情報
    2. 入退館、警備、防災、避難及び施設安全に関する事項
    3. 顧客又は第三者への差し迫った被害を防止するための緊急措置
    4. 違法な販売行為又は個人情報の漏えいを直ちに停止するための措置
    5. その他当社への事前確認が困難であり、緊急に対応する合理的必要がある事項
  5. 利用者は、当社の承諾なく、同一案件について協力会社又は店舗担当者等と直接契約し、又はこれらの者から直接報酬を受領してはなりません。

第13条（代替者及び再委託）

  1. 顧客情報の取扱い、資格要件、会場セキュリティその他案件の性質上、個別条件に別段の定めがない限り、利用者本人が委託業務を遂行するものとします。

第14条（完了報告及び業務完了確認）

  1. 利用者は、個別条件に従い、委託業務の開始、終了、実施内容、販売促進活動の状況、事故又は苦情の有無その他必要な事項を報告します。

第15条（委託報酬及び支払）

  1. 委託報酬の額、消費税の取扱い、算定方法及び支払期日は、個別条件に定めます。
  2. 当社は、業務完了確認後、個別条件に定める具体的な支払期日に、利用者が指定する金融機関口座へ振り込む方法により委託報酬を支払います。
  3. 支払期日は、適用される法令に従い、当社が役務の提供を受けた日から60日以内のできる限り短い期間内に設定します。

第16条（費用、税務及び保険）

  1. 交通関連費用、宿泊費、通信費、機器費その他の費用は、個別条件に定めるところに従うこととし、個別条件に記載のない場合には原則として利用者の負担とします。
  2. 実費精算を行う費用について、利用者は、当社所定の期限までに領収書その他の証憑を提出します。
  3. 利用者は、自らの事業に関する所得税、消費税、地方税、社会保険料その他の公租公課を、自らの責任で申告し、納付します。
  4. 当社は、法令上必要な場合、委託報酬から源泉徴収を行い、法令に従って処理します。

第17条（予定変更、キャンセル及び不可抗力）

  1. 個別契約成立後の実施予定日、実施場所又は委託業務の変更は、当社と利用者の合意によります。
  2. 利用者が個別契約の履行を中止し、又は予定どおり遂行できない事情が生じた場合、利用者は直ちに当社へ通知し、損害の拡大防止及び代替対応に合理的に協力します。
  3. 利用者は、正当な理由及び事前連絡なく、委託業務を実施せず、又は途中で放棄してはなりません。
  4. 天災地変、感染症の重大な拡大、法令又は行政措置、交通機関の大規模な途絶、会場の使用不能その他当事者の合理的な支配を超える事由により履行が困難となった場合、当事者はその責任を負いません。

第18条（携帯販売、顧客保護及び法令遵守）

  1. 利用者は、委託業務の遂行に当たり、電気通信事業法、個人情報保護法、携帯電話不正利用防止法、消費者契約法、特定商取引法、割賦販売法、不当景品類及び不当表示防止法その他適用される法令、行政指針並びに携帯電話事業者等の適法なルールを遵守します。
  2. 利用者は、次の行為をしてはなりません。
    1. 虚偽又は誤解を招く説明
    2. 重要事項の不告知又は不十分な説明
    3. 顧客の意思に反する継続的又は威迫的な勧誘
    4. 顧客の明確な同意を得ないオプション、サービス又は商品への申込み
    5. 顧客になりすました署名、入力、申込み又は本人確認
    6. 本人確認書類の不正取得、改変又は目的外利用
    7. 権限のない値引き、特典、審査結果又は契約成立の約束
    8. 顧客の判断能力、知識又は状況につけ込む勧誘
    9. その他顧客の利益を不当に害する行為
  3. 利用者は、顧客から苦情、取消し、解約、補償その他の申出を受けた場合、権限の範囲を超えて回答又は約束をせず、速やかに当社へ連絡します。

第19条（秘密保持）

  1. 秘密情報とは、案件情報、個別条件、委託報酬、協力会社又は店舗に関する情報、商品・サービス情報、販売手法、マニュアル、システム情報、認証情報、顧客情報、苦情情報、営業情報、登録者等の氏名、連絡先、アカウント情報、案件参加状況、稼働状況、報酬条件その他登録者等に関する情報その他当社又は第三者から開示された一切の非公開情報をいいます。
  2. 次の情報は秘密情報に含まれません。
    1. 開示時点で公知であった情報
    2. 開示後、利用者の責めに帰すべき事由によらず公知となった情報
    3. 開示前から利用者が適法に保有していたことを証明できる情報
    4. 秘密保持義務を負うことなく第三者から適法に取得した情報
    5. 秘密情報によらず独自に取得又は開発したことを証明できる情報
  3. 利用者は、秘密情報を委託業務の遂行以外の目的で使用し、又は当社の承諾なく第三者に開示してはなりません。
  4. 利用者は、法令、裁判所又は行政機関の命令により秘密情報を開示する必要がある場合、法令上可能な範囲で事前に当社へ通知します。
  5. 利用者が、弁護士、税理士その他法令上守秘義務を負う専門家への相談、行政機関への適法な申告、公益通報又は自己の権利保全のために必要な範囲で情報を使用することは、本条違反となりません。
  6. 利用者は、個別契約終了時又は当社から求められた場合、秘密情報を返却又は削除します。ただし、法令遵守又は紛争対応のため保存が必要な情報を除きます。

第20条（禁止事項）

  1. 利用者は、本サービス又は委託業務に関し、次の行為をしてはなりません。
    1. 虚偽又は不正確な情報を登録し、又は重要な情報を隠す行為
    2. 本サービス又は情報システムへの不正アクセス、妨害又は過度な負荷を生じさせる行為
    3. 案件情報、秘密情報又は顧客情報の不正取得、外部共有又は目的外利用
    4. 正当な理由及び連絡なく、委託業務を実施せず、又は途中で放棄する行為
    5. 当社の承諾を得ない代替者の使用又は再委託
    6. 当社を介さず、同一案件について協力会社等から直接依頼又は報酬を受ける行為
    7. 顧客、協力会社又は店舗担当者等に対し、自らへの直接発注を働き掛ける行為
    8. 当社に確認すべき重要な条件変更を、店舗担当者等との間で独自に合意する行為
    9. 法令又は本規約に違反する販売、勧誘、本人確認又は申込み処理
    10. 暴力、脅迫、差別、嫌がらせ、セクシュアルハラスメント、パワーハラスメントその他第三者の尊厳を害する行為
    11. 酒気帯び、違法薬物の使用その他正常な業務遂行が困難な状態で委託業務を行う行為
    12. 金品の横領、窃取、不正な受領、贈収賄又はリベートの授受
    13. 当社、協力会社、店舗、顧客又は第三者の信用を害する目的で、虚偽の事実を公表又は流布する行為
